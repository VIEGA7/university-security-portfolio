# Многокритериальный анализ, вариант 11

Здесь я собрал материалы своих КДЗ №1–5 по многокритериальному анализу. Основа — мои отчёты `KDZ_1.docx` … `KDZ_5.docx` по дисциплине «Формализованные модели и методы информационно-аналитического мониторинга». Для извлечения листингов и подготовки новой расчётной версии я использовал помощь ИИ.

В `extracted/` я сохранил пять извлечённых Python-листингов: КДЗ №1, №2, №3 и две версии №5. Проверен синтаксис; их зависимости и исходные графические результаты здесь не запускались. Для КДЗ №4 листинг отсутствовал: формулы восстановлены из математических объектов Word и сверены со скриншотом области допустимых решений.

В `analysis.py` я публикую новую проверенную версию без внешних зависимостей:

- №1: 200 точек в заданной эллиптической области, множество Парето, индекс эффективности, кластеризация. При равных расстояниях выбран кластер с меньшим номером; генератор имеет фиксированный seed.
- №2: минимизация двух критериев и Ω-доминирование по крайним допустимым весам `(0.4, 0.6)` и `(0.7, 0.3)`. По умолчанию 200 точек вместо исторического запуска на 100 и 10000.
- №3: метод главного критерия, результат `(24.75, 30.25)`, значения критериев `(55, -44, -66)`.
- №4: последовательные уступки по `f2` на 2 и по `f1` на 3; этапы `(0,16.5)`, `(2/3,16.5)`, `(0,14.5)`.
- №5: минимум суммы квадратов отклонений от идеальных значений. Идеальная точка пересчитана без округления; решение приблизительно `(11.366667,10.633333)`. Метод решения заменён точным перебором кандидатов на двумерном многоугольнике; это не повторный запуск исходного Франка—Вульфа.

```powershell
python portfolio/multicriteria-analysis/analysis.py --output portfolio/multicriteria-analysis/output
```

Результат — CSV для №1–2 и JSON для №3–5. Файлы появляются в `output/` и не включаются в Git. Версия на стандартной библиотеке не рисует исторические графики и не создаёт Excel с исходным оформлением.

Численные проверки выполняются общей командой `python -m unittest discover -s tests -p test_reconstructed.py -v`. Проверены допустимость решений, значения №3–4, граница и локальная оптимальность №5, корректность доминирования с дубликатами и связь Ω-множества с Парето.

Для запуска именно извлечённых листингов нужны 64-битный Python и пакеты из `extracted/requirements.txt`. Исторические версии библиотек неизвестны, поэтому это список зависимостей, а не восстановленный lock-файл. Запускайте листинги в отдельном рабочем каталоге: исторические программы записывают Excel/CSV и открывают графики.
