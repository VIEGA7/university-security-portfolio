# Linux, HTTP, nginx и JavaScript

В этом каталоге я публикую частично восстановленные практики УиУИБАС №3–5 и №7: nginx, порт 31337, ресурс с Basic Auth, XHR-запрос к JSON и вычисление суммы. Пути конфигурации адаптированы для контейнера вместо исходной Ubuntu.

В `www/array.json` восстановлен массив из текста задания; сумма — 144. Файл `sensitive_info.txt` содержит только синтетический текст.

## Запуск

В Linux с установленным `htpasswd` создать локальный файл паролей. Команда запросит пароль интерактивно; файл исключён из Git:

```bash
htpasswd -cB portfolio/linux-http-labs/.htpasswd demo
docker compose -f portfolio/linux-http-labs/compose.yaml up -d
```

При повторном добавлении пользователя не указывайте `-c`: этот параметр создаёт файл заново. Открыть `http://127.0.0.1:31337`.

Проверить:

```bash
curl -i http://127.0.0.1:31337/sensitive_info.txt
curl -i -u demo http://127.0.0.1:31337/sensitive_info.txt
docker compose -f portfolio/linux-http-labs/compose.yaml exec nginx nginx -t
```

Первый запрос должен вернуть 401, второй после правильного пароля — 200. Basic Auth поверх HTTP не шифрует пароль; этот пример привязан к loopback, для сетевого использования нужен HTTPS.
