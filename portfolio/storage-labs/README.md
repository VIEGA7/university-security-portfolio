| Практика | Восстановлено | Происхождение и ограничения |

| №4 | MongoDB, импорт STIX, запросы | Скрипт восстановлен частично по image18.jpg; вместо удаления всей коллекции используется upsert по id/modified |

| №7 | MinIO + Neo4j, загрузка/скачивание объекта | Версия MinIO взята со скриншота. Скрипт частично реконструирован; Cypher-сценарий новый. Распределённый кластер MinIO не восстановлен |
| №8 | Spark: загрузка CSV, группировки и средний размер пакета | По скриншотам 10, 11, 14, 15; исходного notebook и CSV нет |

## Запуск сервисов

Нужен Docker Compose. В текущем терминале задайте пароль нужного сервиса (`POSTGRES_PASSWORD` и `PGADMIN_PASSWORD`, либо `MONGO_PASSWORD`, `REDIS_PASSWORD`, `MINIO_PASSWORD` и `NEO4J_PASSWORD`). Значения не сохраняйте в Git. Compose-файлы лежат в соответствующих подкаталогах.

```powershell
docker compose -f portfolio/storage-labs/mongodb/compose.yaml up -d
```

Все опубликованные порты привязаны к `127.0.0.1`. Для pgAdmin сервер PostgreSQL внутри сети называется `postgres`, порт `5432`. Снаружи PostgreSQL доступен на `54310`. Пароли в примерах не заданы.

`mongodb/load_mitre.py bundle.json --dry-run` проверяет локальный STIX bundle без подключения и без сторонних библиотек. Для реального импорта нужен pymongo и `MONGO_PASSWORD`. Исходный MITRE bundle я не включаю в репозиторий; источник данных — [MITRE ATT&CK](https://attack.mitre.org/), его происхождение и условия использования следует сохранять вместе со скачанной версией.

Для MinIO нужен пакет `minio`, для Spark — PySpark и совместимая Java. В `requirements.txt` перечислены зависимости. Необязательно ставить все пакеты: выбирайте нужный для своей лабораторной.

```powershell
python portfolio/storage-labs/minio-neo4j/minio_demo.py
python portfolio/storage-labs/spark/analyze.py path/to/cybersecurity_attacks.csv
```

Spark ожидает столбцы `Traffic Type`, `Protocol`, `Packet Length`. Он не скачивает произвольные данные и не выдаёт вымышленные исторические результаты. Контейнер Jupyter без пароля и запуск от root из старого скриншота не воспроизводились.

## Статус проверки

Python-файлы проверены на синтаксис; dry run валидатора STIX выполнен на синтетическом примере. Docker, сервисы, SDK MongoDB/MinIO и Spark здесь не запускались. Версии образов PostgreSQL/MongoDB/Redis/Neo4j выбраны для реконструкции и отличаются от исторического `latest`; интеграционная совместимость ещё требует проверки. Конфигурации не являются готовым промышленным развёртыванием.
