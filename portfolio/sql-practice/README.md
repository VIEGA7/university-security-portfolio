# SQL-практикум по учебной БД автосервиса

В этом каталоге я публикую свои учебные SQL-материалы по базе автосервиса. Я перенёс листинги из отчёта `90 Заданий по базам данных/Задачи.docx` в `queries.sql`, сохранив формулировки заданий и запросы PostgreSQL. Числа строк в комментариях перенесены из отчёта и не подтверждены повторным запуском; результаты запросов с текущей датой меняются со временем.

В публикационную версию я включил следующие точечные исправления:

- маски `TO_CHAR` записаны строками в одинарных кавычках;
- ежегодная потеря 6% **первоначальной** стоимости выражена как `cost * (1 - 0.06 * years)`, что допускает отрицательный остаток по условию. Исторический `POWER(0.94, years)` описывал другую модель.
- в задаче «только по понедельникам» исключается автомобиль целиком, если хотя бы одно посещение нарушает условие;
- «только у разных механиков» проверяется сравнением числа посещений и числа различных механиков; единственное посещение также подходит;
- в последнем запросе разделены среднее и настоящая медиана, стандартное отклонение вычисляется без фиксированного числа 161.

Исходная БД, DDL и дамп у меня не сохранились. Я не восстанавливал схему по одним упоминаниям таблиц; повторное выполнение запросов не подтверждено. Этот каталог — восстановленный учебный материал, а не полностью проверенный набор 90 правильных решений.

Эти исправления следуют из текста условий; они не подтверждены выполнением на исходной БД. Остальные решения не проходили полный содержательный аудит. Исторические ответы в комментариях после исправлений могут отличаться от нового результата.
