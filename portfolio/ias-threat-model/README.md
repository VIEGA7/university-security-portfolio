## Исправление МИАС №6–8

В исходном отчёте `N=00` задаёт нулевые интенсивности. Это допустимый граничный случай процесса Пуассона, но из него нельзя заключить, что система «абсолютно безопасна». Изоляция от сети также не исключает внутренних нарушителей и съёмных носителей.

В `poisson_model.py` я сохранил этот случай и добавил **отдельный демонстрационный параметр N=11**. Я не выдаю его за установленный исходный вариант. Интенсивности измеряются в попытках в сутки: `γ1=N×0.01`, `γ2=N×0.02`. Для двух нарушителей предполагаются независимые пуассоновские потоки.

```powershell
python portfolio/ias-threat-model/poisson_model.py --n 0 --output portfolio/ias-threat-model/output/zero.csv
python portfolio/ias-threat-model/poisson_model.py --n 11 --output portfolio/ias-threat-model/output/example11.csv
```

При N=11 вероятность хотя бы одной попытки за 30 суток от первого нарушителя ≈0.963117; ожидаемое число попыток двух нарушителей за 14 суток — 4.62. В CSV отдельно учитывается вероятность более четырёх попыток: первые пять значений распределения не выдаются за полное распределение.

**Попытки не равны успешным атакам.** Для оценки компрометации потребуются дополнительные допущения о вероятности успеха и эффективности мер защиты.

## Ограничения модели угроз

Коды и названия угроз в Excel и исходных схемах я сохранил для сопоставления с учебными работами. Их соответствие актуальному БДУ, полнота перечня, уместность классификаторов и нормативных ссылок не сертифицировались. В исходном описании УБИ.030 был смешан сценарий фишинга с использованием учётных данных по умолчанию: для последнего нужен сценарий входа с неизменёнными стандартными данными. Этот пример исправлен в текстовой редакции отчёта; весь перечень требует отдельной содержательной проверки.

Результаты экспертной оценки отражают учебные мнения. Нормированные баллы и ранги сами по себе не являются измеренной вероятностью реализации угроз.
