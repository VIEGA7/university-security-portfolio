1. Сенсоры на межсетевых экранах и IDS.2. Агенты на серверах (БД, файловые, приложений) и АРМ пользователей.3. Система хранения данных (для архива логов).

Выделенный сервер или кластер серверов (Сервер сбора событий SIEM в Служебном сегменте).

Производитель: 1С (например, «1С:Управление холдингом» или «1С:ERP Управление холдингом»).Стоимость: Лицензия на 55 пользователей – от 500 000 руб., плюс внедрение и доработка.Преимущества: Единая платформа с уже имеющейся бухгалтерией, глубокая детализация финансовых показателей.Недостатки: Сложность настройки под отраслевые (проектные) особенности.

Обеспечивает консолидацию финансовой отчетности, бюджетирование, план-факт анализ, расчет эффективности подразделений.

1. Сервер 1С:Предприятие.2. Сервер базы данных SQL.3. АРМ финансового директора, бухгалтеров, руководителей проектов.

Тот же сервер, где развернута 1С (сервер приложений и сервер БД в Защищенном сегменте серверов).

4. PDM-система (управление инженерными данными)

Производитель: Microsoft SQL Server (основная платформа) с прикладным ПО для управления инженерными данными (например, собственные разработки или специализированные системы на базе SQL).Стоимость: Лицензирование SQL Server – от 150 000 руб. за процессор; разработка и внедрение прикладного слоя – от 500 000 руб.Преимущества: Высокая производительность, масштабируемость, поддержка транзакций, интеграция с существующей инфраструктурой 1С и CAD-системами через API.Недостатки: Требует квалифицированных администраторов баз данных (DBA); сложность настройки прав доступа к инженерным данным.

1. Хранение инженерных данных (чертежи, 3D-модели) в структурированном виде.2. Ведение электронной структуры изделия/проекта.3. Контроль версий и изменений проектной документации.4. Организация коллективной работы над проектом через единое хранилище.

1. Выделенный сервер базы данных SQL.2. Файловое хранилище проектной документации (связка с BLOB-полями SQL или отдельное хранилище).3. АРМ инженеров-проектировщиков (рабочие станции с CAD и клиентами БД).

Выделенный сервер (или кластер) с высокопроизводительной дисковой подсистемой в Защищенном сегменте серверов.

Описание схемы «Архитектура информационно-аналитической системы ООО «АтомЭнергоПроект» (с интеграцией ИАС)»

Разработанная архитектура информационно-аналитической системы (ИАС) предприятия представляет собой многоуровневую структуру, обеспечивающую сбор, интеграцию, хранение, анализ и представление данных для поддержки принятия управленческих решений. Схема демонстрирует полный цикл обработки информации — от источников до конечных пользователей.

1. Уровень сбора данных (Источники)

На данном уровне осуществляется первичный сбор информации из различных гетерогенных источников предприятия:

1С:Управление проектами, Бухгалтерия, Договорной отдел — источник операционных данных, содержащий информацию о финансово-хозяйственной деятельности, договорах, зарплате, учете материалов. Данные имеют структурированный формат (таблицы БД).

Файловый сервер (Проекты, сметы, Excel) — хранилище неструктурированных и слабоструктурированных данных: проектная документация, сметные расчеты в Excel, технические задания, переписка. Требует дополнительной обработки для извлечения значимой информации.

CAD/PDM-система (Инженерные данные) — специализированное ПО для автоматизации проектирования и управления инженерными данными. Содержит чертежи, 3D-модели, спецификации, ведомости материалов (техническая документация).

Сенсоры ИБ (FW, IDS, Серверы) Логи событий — источники данных об информационной безопасности: журналы событий межсетевых экранов, систем обнаружения вторжений, серверов приложений и ОС. Используются для выявления инцидентов и анализа защищенности.

2. Уровень интеграции (ETL-процессы)

Центральный узел интеграции — ETL-процессы (Extract, Transform, Load). Данный компонент выполняет ключевые функции:

Извлечение (Extract) — получение данных из всех источников первого уровня с заданной периодичностью (пакетный режим, микропакеты, потоковая передача).

Преобразование (Transform) — очистка данных от дубликатов и ошибок, приведение к единым форматам, обогащение справочной информацией, агрегация, вычисление производных показателей.

Загрузка (Load) — запись преобразованных данных в централизованное хранилище.

ETL-процессы обеспечивают согласованность, полноту и качество данных, поступающих в аналитическую систему.

3. Уровень хранения (Хранилище данных)

Хранилище данных (Data Warehouse) представляет собой централизованное репозиторий, организованный по предметно-ориентированному принципу. Особенности уровня:

Интеграция данных из всех источников в едином пространстве.

Поддержка историчности (хранение данных за длительные периоды с возможностью анализа динамики).

Оптимизация структуры для аналитических запросов (звезда, снежинка).

Обеспечение непротиворечивости и целостности данных.

Хранилище служит «единственным источником правды» (Single Source of Truth) для всех последующих аналитических систем.

4. Уровень витрин данных (Data Marts)

Для повышения производительности и упрощения доступа к данным создаются специализированные витрины данных — подмножества хранилища, ориентированные на конкретные предметные области:

Витрина «Проекты» — содержит данные о ходе выполнения проектов, этапах, ресурсах, сроках, загрузке персонала.

Витрина «Финансы» — агрегирует финансовые показатели: бюджеты проектов, фактические затраты, отклонения, прибыльность.

Витрина «ИБ» — хранит данные о событиях безопасности, инцидентах, уязвимостях, действиях пользователей.

Витрина «Инжиниринг» — содержит метаданные об инженерных объектах, версиях документации, статусах согласования.

Каждая витрина оптимизирована под задачи соответствующих аналитических приложений и групп пользователей.

5. Уровень анализа (Информационно-аналитические системы)

На данном уровне работают специализированные ИАС, каждая из которых решает свой круг задач:

BI-платформа (Deductor) Управление проектами — инструмент бизнес-аналитики для построения отчетов, дашбордов, OLAP-кубов. Позволяет руководителям проектов и аналитикам отслеживать ключевые показатели эффективности (KPI) проектной деятельности в режиме реального времени.

Системы Kaspersky (Аналитика ИБ) — класс SIEM-систем (Security Information and Event Management) для сбора, корреляции и анализа событий информационной безопасности. Выявляет аномалии, атаки, инциденты, формирует отчетность для регуляторов.

1С:Управление холдингом (Фин. анализ, KPI) — аналитическая надстройка над учетной системой 1С. Обеспечивает консолидацию финансовой отчетности, бюджетирование, план-факт анализ, расчет эффективности подразделений.

PDM-система (Microsoft SQL Server) Инжиниринг — система управления инженерными данными (Product Data Management). Контролирует версионность чертежей, управляет структурой изделий, обеспечивает коллективную работу над проектной документацией.

6. Уровень пользователей

Конечные потребители аналитической информации, разделенные по ролям и задачам:

Руководители проектов, Аналитики — работают с BI-платформой для контроля сроков, ресурсов и результатов проектов.

Специалисты ИБ, Администраторы — используют SIEM-систему для мониторинга защищенности и реагирования на инциденты.

Финансовый директор, Бухгалтерия — взаимодействуют с аналитическими модулями 1С для финансового планирования и анализа.

Главный инженер, Проектировщики — работают в PDM-системе с инженерными данными и документацией.

Ключевые особенности архитектуры

Многоуровневость — четкое разделение функций между уровнями сбора, интеграции, хранения, анализа и представления.

Централизованное хранилище — обеспечивает согласованность данных и исключает информационную разобщенность.

Специализированные витрины — повышают производительность запросов и упрощают разработку аналитических приложений.

Интеграция разнородных систем — в единую архитектуру объединены операционные (1С), инженерные (CAD/PDM) и специализированные (SIEM) системы.

Ролевая модель доступа — различные группы пользователей имеют доступ только к релевантным для их задач данным и инструментам.

Ответы на контрольные вопросы

1. Информационно-аналитическая система (ИАС) – это класс информационных систем, предназначенных для сбора, хранения, обработки и анализа данных с целью поддержки принятия управленческих решений. ИАС объединяет методы обработки данных, средства накопления информации, математические модели и программные инструменты для выявления скрытых закономерностей и тенденций. [3, Белов В.С.]

2. Функционал ИАС – совокупность задач, операций и процедур, реализуемых системой для достижения целей анализа и поддержки принятия решений. Включает: сбор и консолидацию данных, их очистку и преобразование, многомерный анализ (OLAP), интеллектуальный анализ данных (Data Mining), визуализацию результатов, прогнозирование и моделирование ситуаций. [3, Белов В.С.; 4, Зариковская Н.В.]

3. Классификация существующих ИАС

Информационно-аналитические системы классифицируются по следующим основным признакам:

По уровню принимаемых решений:

Стратегические ИАС – ориентированы на высшее руководство, поддержка долгосрочного планирования (например, системы бизнес-моделирования).

Тактические ИАС – для среднего звена управления, анализ функциональной деятельности (финансы, маркетинг, производство).

Оперативные ИАС – для специалистов, оперативный анализ текущих процессов (OLAP-системы).

По предметной области:

Финансово-экономические (бюджетирование, план-факт анализ).

Маркетинговые (анализ рынка, CRM-аналитика).

Технологические (управление производством, SCADA-аналитика).

ИБ-аналитические (SIEM, аналитика инцидентов, поведенческий анализ).

По способу обработки данных:

OLTP-системы (транзакционные) – оперативная обработка, основа для ИАС.

OLAP-системы – многомерный анализ исторических данных.

Data Mining-системы – интеллектуальный поиск закономерностей.

Ситуационные центры – комплексный анализ с визуализацией и моделированием. [3, Белов В.С.; 4, Зариковская Н.В.]

4. Наиболее распространенные ИАС

Среди наиболее распространенных ИАС можно выделить:

Deductor (BaseGroup) – отечественная платформа, включающая ETL, хранилище, OLAP и Data Mining.

Прогноз – российская платформа для ситуационных центров и аналитики.

SAP Business Objects, IBM Cognos, Oracle BI – зарубежные BI-платформы.

1С:Аналитика, 1С:Управление холдингом – аналитические решения на базе 1С.

MaxPatrol SIEM, Kaspersky SIEM – ИАС в области информационной безопасности.

Лоцман:PLM, ADEM – ИАС для управления инженерными данными и проектированием. [3, Белов В.С.]

5. Отличия систем мониторинга ИБ и аудита ИБ от ИАС

Системы мониторинга ИБ (например, SIEM) ориентированы на сбор событий в реальном времени, корреляцию, выявление инцидентов и оповещение. Их цель – оперативное обнаружение атак и нарушений. Они работают преимущественно с текущими данными. [2, ГОСТ Р 53114-2008]

Системы аудита ИБ предназначены для периодической проверки соответствия состояния ИБ установленным требованиям и стандартам. Они выдают "срез" состояния на момент проверки, формируют отчетность для регуляторов и руководства. [2, ГОСТ Р 53114-2008]

ИАС в отличие от них, решают более широкий круг задач, выходящих за рамки только безопасности. ИАС могут использоваться для анализа финансовых показателей, эффективности проектов, маркетинговых исследований. Даже в сфере ИБ, ИАС (в отличие от SIEM) ориентированы на глубинный анализ накопленных данных об инцидентах, выявление трендов, прогнозирование рисков, поддержку стратегических решений по развитию системы защиты, а не только на оперативное реагирование. [1, ГОСТ Р 51275-2006; 3, Белов В.С.]
